# Vibes Modded

Модифицированная версия расширения **Vibes** для Chromium-браузеров.

В этом моде добавлены русский язык интерфейса, ванильный режим и поддержка ВКонтакте. Остальные возможности, которые уже есть в оригинальном расширении, здесь не выдаются за изменения мода.

## Изменения мода

- Русская локализация интерфейса.
- Ванильный режим работы.
- Поддержка страниц ВКонтакте (`vk.com` и `vk.ru`).

## Установка

В репозитории находится распакованная версия расширения без отдельного установщика.

1. Скачайте репозиторий через **Code → Download ZIP** или клонируйте его.
2. Откройте `chrome://extensions` в Chromium, Google Chrome или совместимом браузере.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите каталог, в котором находится `manifest.json`.
6. Закрепите Vibes на панели браузера.

После изменения исходников откройте `chrome://extensions` и нажмите **Обновить** у расширения.

## Использование

1. Откройте страницу с аудио или видео.
2. Откройте Vibes через иконку расширения.
3. Выберите русский язык в настройках, если он не включился автоматически.
4. Включите нужный режим и настройте расширение.

Для ВКонтакте расширение можно использовать на страницах с доступным аудио или видео. На VK полная обработка pitch/reverb зависит от источника аудио и CORS: для CDN без подходящего CORS расширение использует speed-only режим, чтобы не ломать звук. В таком случае для полного управления можно попробовать **Tab Capture**.

## Структура

```text
manifest.json       Манифест расширения Chrome Manifest V3
popup.html/css/js    Интерфейс popup
background.js        Service worker
backend/             Обработка захвата и аудио
ui/                  Элементы интерфейса и режимы
lang/                Локализации и языковые данные
_locales/            Локализации Chrome
resources/           Иконки и статические ресурсы
welcome.html         Приветственная страница
```

## Разработка

Проект не использует package manager и отдельный build-шаг. Исходники можно изменять напрямую, после чего перезагрузить расширение на странице `chrome://extensions`.

Автоматические тесты не настроены. Для ручной проверки рекомендуется проверить:

- загрузку расширения через **Загрузить распакованное расширение**;
- переключение русского языка;
- работу ванильного режима;
- работу на `vk.com` и `vk.ru`;
- сохранение настроек после перезагрузки расширения.
